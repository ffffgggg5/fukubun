# 復文 - 英語学習アプリ

英語学習法「復文」を毎日続けるための、自分専用のローカルWebアプリです。

## 復文とは

1. 英文が表示される → その日本語訳をタイピングする
2. 「答え」ボタンで正解の日本語訳を表示 → 自分で ⭕️/❌️ を判定
3. 続けて、その日本語文だけが表示される → 今度は英訳をタイピングして復元する
4. 「答え」ボタンで正解の英文を表示 → 自分で ⭕️/❌️ を判定

書くことで自分の弱点に気づける学習法です。

## 主な機能

- 英文カード（Excelからインポート）と、気づきを記録するメモカード（一問一答）
- Ankiのような簡易SRS（間隔反復）システム
  - ⭕️: 間隔を 1→3→7→14→30→90 日と延長
  - ❌️: 間隔を 1日にリセット
- 毎日、新規カード（ランダム順、1日10件まで）と復習期日が来たカードが自動で表示される
- 回答時にその問題の過去の回答履歴を確認できる
- 連続学習日数（ストリーク）カウンター

## セットアップ

```bash
npm install
npm run dev
```

http://localhost:3000 を開いてください。データは `data/fukubun.db`（SQLite）にローカル保存されます。

## Excelから問題をインポートする

A列＝英文、B列＝和訳の2列のExcelファイルを用意し、以下を実行します。

```bash
npm run import -- path/to/questions.xlsx
```

オプション:

- `--skip-header` : 1行目が見出し行の場合に指定
- `--swap` : A列が和訳、B列が英文の場合に指定
- `--sheet=シート名` : 1枚目以外のシートを使う場合
